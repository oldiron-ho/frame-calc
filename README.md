# FrameCalc Web

Next.js 기반 모바일 우선 난간 계산기입니다.

## 주요 기능

- 전체 길이(mm), 간격 개수, 난간 두께(mm) 기반 난간 배치 계산
- 난간 개수와 동일 간격 요약 표시
- 난간 시작/끝 위치 결과 표시
- 최근 유효 계산 자동 저장, 재불러오기, 삭제
- 모바일 화면 최적화 레이아웃

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 품질 확인

```bash
npm run lint
npm run test
npm run build
```
